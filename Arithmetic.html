An Algebra 1 course prepares students to be able to solve the following:

  • Linear equations with 1 variable
  • Quadratic equations
  • Linear systems of equations with 2 variables
  • Quadratic systems of equations with 2 variables

An Algebra 2 course prepares students to be able to solve the following:

  • Larger systems of equation with more than 2 variables
  • Non-linear system of equation(not only quadratic)
  • Specific cubic equations
  • Non-linear equations including natural logarithm (ln), cube roots, and exponential equations

However, there are some equations that even advanced high school math courses don't teach students how to solve.

A very common problem that confuses students is a cubic equation that is not factorable. An example being, f(x)=x^3+7x+3

This cubic polynomial from graph analysis only has 1 real solution that makes f(x)=0. Meaning there is only 1 value that makes x^3+7x+3 equal to 0.

Now you may be wondering, how do I solve this? Well, I have to say that this equation is very hard to solve by hand or even with a low function calculator unable to stack roots inside roots.

You can find the exact value of this equation by using a formula that is so lengthy, people make mistakes from typing it on their phone or calculator. So this is why solving this by exact method is unethical. This page exactly solves that issue!

You can approximate the value of the equation very precisly using a calculus method of approximation. The demonstration of such procedure will be below:

If you take the derivative of any function and draw a tangent line near the point at which the function equals to zero, the straight line approximating the solution to the function is extremely close.

Remember f(x)=x^3+7x+3. It's derivative can be found using a simple rule... Take the power of the variable and multiply the coefficent by it. Then take down the power by 1. the derivative of f(x) is 3x^2+7 and because constants have a power of x^0, anything multiplied by 0 is 0 so it "disappears".

Now that this is the derivative, 3x^2+7. We need to find a value such that f(that #) is pretty close to 0. You should know how to substitute numbers into a function if you have taken Algebra I or II. Testing values of the function, we have this list of numbers:

  1. f(-3)=-45
  2. f(-2)=-19
  3. f(-1)=-5
  4. f(-1/2)=-0.625
  5. f(0)=3

The value closest to 0 is -1/2 which means it's the best approximation. Now to draw a tangent line at that position to actually approximate it good. We substitute in -1/2 into 3x^2+7 and get the slope of the line to be 31/4. Now using point slope form of an equation, slope(x-xposition)+yposition makes a line that crosses (xposition,yposition) with the slope.

After placing in the values, the approximation tangent line is 31/4(x+1/2)-5/8. If you set this tangent line expression equal to zero, the value of x is a simple linear equation answer. After solving, you would get -13/31 as x. If you want to make your calculations more precise, you can repeat the process.

Sub in x=-13/31 into f(x) which gives you f(-13/31)=-275/29791..... Sub in x=-13/31 into derivative equation 3x^2+7 which equals 7234/961. Substitute into point slope form:7234/961(x+13/31)-275/29791

The final step is to solve the equation for zero. The solution in fraction is -93767/224254. Into decimals, the answer is approximately

-0.4181285506613

The real solution to the equation calculated by a software is -0.4181282993... which means this fractional approximation has 5 digits of accuracy after the decimal. If you want an exact value using the trigonometric method, then visit a different webpage (Solving complex equations).
